FM Tactician - build steps
1. Install Android Studio (free) on a PC.
2. File > Open > select this FMTactician folder. Let Gradle sync.
3. Plug in your phone (USB debugging on) and press Run, or Build > Build APK(s) and copy the APK to your phone.
4. On the phone: open FM Tactician, tick squad strengths, allow overlay, tap Start bubble.
5. Open Football Manager, go to the opponent's scouting/analysis screen, tap the bubble.
Edit RULES in TacticsEngine.kt to match the exact wording FM26 shows.
